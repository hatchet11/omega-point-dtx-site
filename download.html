Omega Point DTX
Overview

Download and activate

DTX runs on your hardware. The package and your licence key both come from your Omega Point account — the download is tied to an active subscription, so it is not a public link.

1 · Get the package and your key

Sign in, then use Download and Issue licence key on the Omega Point DTX row.

Open your account

The licence key is shown once. Only a hash of it is stored, so it cannot be shown again — a lost key is reissued, not recovered.

2 · Verify the file before you run it

The SHA-256 is shown next to your download, and is also returned with the file itself in the X-Artifact-SHA256 header. Check it:

Get-FileHash .\OmegaPointDTX-<version>.zip -Algorithm SHA256

This is a security product. Verifying the bytes you were sent is the minimum, and we publish the hash so you can.

3 · Install

Unzip, then from inside the folder in PowerShell:

.\Install-OmegaPointDTX.ps1 -LicenseKey DTX-XXXXX-XXXXX-XXXXX-XXXXX-XXXXX

It self-elevates — administrator rights are required, because the Windows Security event channel cannot be read without them and a sensor that cannot read it silently misses every logon and process-creation detection.

The installer activates your licence before scheduling anything, so a bad key fails immediately instead of leaving a task that quietly does nothing every 15 minutes.

Requirements

  • Windows 10/11 or Windows Server 2019+
  • Administrator rights
  • Python 3.11+ — unless you took the package with the runtime embedded

What leaves your machine

Events, alerts and triage results never leave the host. The only outbound call DTX makes is the licence check to id2.omegapointsolutions.com, carrying your licence key, a hashed machine fingerprint and the hostname. Nothing else, ever.

DTX caches a signed entitlement verdict and keeps running for 14 days without reaching that service, so an air-gapped or intermittently connected deployment is not blinded by a dead uplink.

Before you activate

You can prove the detection engine works before the licence is involved:

python dtx_sensor.py --selftest

It runs with no OS and no network calls, and is deliberately not gated.
